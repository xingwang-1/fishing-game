# 深蓝渔场｜捕鱼大作战

独立的桌面网页捕鱼闯关游戏。鱼、海底、渔网和捕获特效由 Canvas 2D 实时绘制，不使用外部图片素材。

## 本地运行

需要 Node.js 20.19 或更新版本。

1. 在项目目录运行 `npm install`。
2. 运行 `npm run dev`，打开终端显示的本地地址。
3. 运行 `npm run build` 可生成生产版本到 `dist/`。

## 操作

| 操作 | 控制 |
| --- | --- |
| 瞄准并发射 | 移动鼠标，单击左键 |
| 切换小、中、大网 | 右键 |
| 键盘备用切网 | N 或 ↑ |
| 暂停 / 继续 | 点击暂停按钮或 Esc |
| 键盘备用发射 | 空格 |

捕鱼进度、已解锁关卡和最佳分数保存在当前浏览器的 localStorage 中。

## 项目结构

- `index.html`：游戏界面、HUD 和菜单
- `src/main.js`：Canvas 绘制、游戏逻辑、输入和进度保存
- `src/style.css`：配色、布局、菜单和响应式界面
